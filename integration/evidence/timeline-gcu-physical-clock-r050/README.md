# GCU per-physical-counter units, run 050

This is a finite installed clock/export milestone, not full three-backend or
GCU asynchronous-pipeline acceptance. No paper or Study artifacts changed.

The default compact producer now records full SIPINFO in each pair's identity
word. On the actual GCU300 device, the SDK's masked SIP ID aliases 0 and 544;
their observed timer origins differ. A separate 64-program anchor sampler
retains twelve recurring full identities. Frozen training and independent
held-out samples bound an empirical rational tick period for each identity and
capture window. They do not grant a common epoch, read precision, exact source
cost, engine busy, or DTE completion timing.

The owned helper bitcode is deterministic, sealed against its source/tool/SDK,
and atomically published with its receipt. Actual cache tests preserved and
rejected corruption and recovered an interrupted publication. The direct LLVM
intrinsic through the upper SDK IR failed; the retained failure motivated the
small wrapped helper linked at the supported SDK stage. SDK private files are
not committed.
