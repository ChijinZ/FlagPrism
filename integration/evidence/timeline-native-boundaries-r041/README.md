# Late NVIDIA native boundary diagnostics (r041)

Based on `de4e968`, this delta binds original PTX instructions to actual SM120
LDGSTS, LDGDEPBAR, BAR.SYNC and LDSM instructions. It checks forward order
relative to inline readers and rejects external entry or unknown internal
control. This is a conditional native-order report, not a timer value-flow,
participation, source-cost, physical completion or dependency-flow certificate.

The default installed hook writes `native_boundary_control_file`. Public
retained-only reexport includes `native_boundaries` in its immutable versioned
control diagnostic; original captures and trace bytes are preserved. Unknown
forms remain per-site unverified. No operator names, paths, shapes or fixed
site/PC identities select the rules.

## Actual execution

All imports, packaging, numerical tests and Trace Processor execution ran in
`chijin-study-pro6000`; full precommit fixed point and Python AST preservation
ran in existing GCU `flagprism-enflame-dev`. The workstation only edited files,
used Git, orchestrated SSH and audited retained bytes with the standard library.

The actual installed wheel passed 23 ordinary/profile mathematical calls plus
four runtime-K GEMM calls, default compiler/derive/copy failure and recovery,
and previous wait-control checks in normal and optimized Python. Core r024 and
standalone r036 native objects were byte-bound and reused unchanged, not rebuilt.

The first installed native-boundary test stopped on an incorrect Python import
(`flagtree_profiler` instead of installed `flagtree.profiler`). The first failure
is retained. Only the test import was corrected; the followup used the same
wheel and original captures, without application replay or device recapture.
Both normal and `-O` tests then passed 170 negative checks and checked 15 sites
in each of two real captures. Default hook diagnostics and public offline
upgrades passed. Sixteen existing isolated trace bytes remained identical;
actual Trace Processor checks passed. No renderer changed and no new browser
run is claimed; r040 UI evidence remains scoped to the unchanged exporter.
