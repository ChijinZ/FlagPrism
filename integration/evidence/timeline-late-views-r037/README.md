normal and optimized Python: 81 tests and two subtests in each mode. Default
API math/multiple calls/streams/warm session produced 13 captures; runtime-K
GEMM produced two full-CTA captures. Each now exports eight explicit observer
views, after whole-raw validation. All original full-CTA raw remains retained;
presentation selection does not reduce collection overhead.

A real compiler subprocess failure launched none; derived-output and receipt

without replay, then the test copied the final bundle and removed its owned
staging directory. Five actual compiler receipts and 28 compiler artifacts
survived, alongside 16 traces. Finalized public session IDs remain no-ops.

Normal and optimized view contracts reject corrupted non-displayed actor
records, mismatched real compiler plans/layouts, duplicate actor selections,

status. These are actual-raw-derived negative fixtures, not device positives.

GPU-hidden offline public/normal/optimized processes reproduced 16 new-layout
and 24 legacy-layout traces byte for byte, with original environment roots
inaccessible and no application replay. Actual Trace Processor imports passed.

`runs/installed-views-v1/output/` retains 48 fresh grouped traces, their canonical
views, original raw, actual TP SQL/protobuf checks, and six standard Perfetto UI
checks/screenshots. All 592 original files remained unchanged. The timeline

## Failure history and limits

The initial source writer failed on a missing required `missing_reason` field;
the field was added. Source UI attempts exposed a wrong browser path and a
legacy semantic expectation. Both were fixed in the harness; their failures
and originals remain. Actual screenshot inspection motivated semantic track
grouping, which changes display lanes without altering endpoints or raw refs.

The first installed receipt checker incorrectly expected the original error
string at the wrapper and public finalization to retry a finalized session.
Existing API behavior preserves the original in `__cause__`; the corrected
checker uses documented retained-hook recovery. The first failure remains.

Full-width machine getters and endpoints are revalidated against original
PTX, CUBIN/debug and SASS text/JSON; this is not a custom full SASS binary decoder.
SM120 units are one nanosecond per tick. Each observer remains in an independent
trace with explicit unverified precision and epoch. Source locations are M:N
navigation, observation order is not a source-loop iteration number, and issue
brackets are not hardware-engine busy intervals. No time flows are produced.
Ascend/GCU full timeline, independent six-math qualification and final three
fresh code reviewers remain outstanding.
