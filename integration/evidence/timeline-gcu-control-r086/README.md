# GCU native direct-control index

The new internal helper indexes explicit branches, conditional fallthrough,
direct calls, returns and exits in a bounded, byte-bound kernel packet extent.
Hardware loops, indirect transfers and unrecognized opcodes remain explicit
unknowns. It does not establish a complete CFG or value provenance.

In the unchanged loaded polynomial object, the shared end-reader packet has
three explicit predecessors. The later shared record body has an additional
entry from a different path. Reader predecessors alone therefore cannot prove
all incoming begin/site values. Original ELF symbols and the vendor kernel
descriptor bound actual code; descriptor bytes in .text are metadata, not
unaccounted instructions. Both original native views remain byte-bound.

Normal and optimized Python each passed 49 related semantic tests. Formatting,
AST and lint checks passed in the existing GCU Docker. The finite independent
review covers this exact source and final execution. This helper remains
source-loaded internal code; no complete source/loop or whole-goal qualification
is claimed. The prior reader implementation was unchanged.

Three bounded CPU diagnostic probes explored compiler-owned debug variables.
The first retained all six variable names and some useful register/stack ranges,
with all runtime-allocated sections unchanged, but its i64 clock expression is
incomplete and ranges end before the shared record body. The second parsed but
SDK codegen failed on an unsupported DIExpression for truncated clock values.
The third described four incoming field roles at ten record groups and compiled,
but changed executable bytes and still left location gaps. These diagnostics
are not a product adapter and do not requalify old loaded captures. Full private
IR, ELF, DWARF and SDK failures remain in root/server receipts outside Git.

No device mathematics, Trace Processor or UI checks were repeated. The complete
receipt archive includes old failures; its SHA index was checked during local
archival. Whole-goal final review remains open.
